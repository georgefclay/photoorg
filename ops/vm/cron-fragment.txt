# Cron fragment installed in `ubuntu`'s crontab on the VM.
#
# The crontab is SHARED with several other sites (crafttags, mineralsmonitor,
# agenticcomplete, etc). NEVER install with `crontab cron-fragment.txt` —
# that would replace the whole crontab and delete the other apps' lines.
#
# Use the fragmented sed pattern the mineralsmonitor site documents:
#   ( crontab -l 2>/dev/null | sed '/# --- photoorg ---/,/# --- END photoorg ---/d' ; \
#     cat ops/vm/cron-fragment.txt ) | crontab -
#
# Times are in the system's local TZ (America/Chicago).

# --- photoorg ---
# Nightly Postgres dump at 03:20 local (America/Chicago). 14-day retention.
20 3 * * *  /home/ubuntu/photoorg/ops/pg_dump_photoorg.sh >> /var/log/photoorg-cron.log 2>&1
# --- END photoorg ---
